<objective>
Migrate password hashing from BCrypt strength=12 to Argon2id with on-login rehash so existing accounts keep working without forced password resets.

Purpose: Argon2id is the OWASP-recommended winner of the Password Hashing Competition; BCrypt strength=12 is no longer the strongest defence available against GPU/ASIC cracking. The rehash-on-login fallback ensures every active account is upgraded silently as users log in, with no breakage for legacy hashes still in the table.
Output: Spring Security uses `Argon2PasswordEncoder` as the default encoder with a delegating routing wrapper that still verifies legacy `$2a$` BCrypt hashes; on a successful login, `passwordEncoder.upgradeEncoding(...)` triggers a rewrite of the stored hash to Argon2id; new registrations and password changes write Argon2id from the start.
</objective>

  <name>Task 1: Add BouncyCastle dependency and switch to a delegating Argon2id-default password encoder</name>
  <files>backend/pom.xml, backend/src/main/java/com/fintrack/common/config/SecurityConfig.java, backend/src/main/resources/db/migration/V37__prefix_legacy_bcrypt_passwords.sql</files>
  <action>
    1. In `backend/pom.xml`, add `<dependency><groupId>org.bouncycastle</groupId><artifactId>bcprov-jdk18on</artifactId><version>1.78.1</version></dependency>` inside the existing `<dependencies>` block, in alphabetical order alongside other libraries. Spring's `Argon2PasswordEncoder` requires it at runtime; without it, encoding throws `NoClassDefFoundError`.
    2. Replace the `passwordEncoder()` bean in `SecurityConfig.java`. Build a `DelegatingPasswordEncoder` keyed on the OWASP-recommended Spring defaults: `Map.of("argon2", Argon2PasswordEncoder.defaultsForSpringSecurity_v5_8(), "bcrypt", new BCryptPasswordEncoder(12))`, default id = "argon2". Call `setDefaultPasswordEncoderForMatches(new BCryptPasswordEncoder(12))` so legacy bare-BCrypt hashes (`$2a$12$...`) without a `{id}` prefix still verify — the V37 migration prefixes all existing rows so this fallback covers only the in-flight rollout window. Update imports; remove the now-unused `BCryptPasswordEncoder` direct import only after verifying it is referenced via the prefix map. Keep the single `@Bean public PasswordEncoder` signature so existing constructor injections do not break.
    3. Create `V37__prefix_legacy_bcrypt_passwords.sql`: `UPDATE users SET password = '{bcrypt}' || password WHERE password LIKE '$2_$%' AND password NOT LIKE '{%}%';` (idempotent — re-running is a no-op). This makes `DelegatingPasswordEncoder` route legacy hashes by their prefix without depending on the `setDefaultPasswordEncoderForMatches` fallback in steady state.
    4. Avoid: do NOT remove the `BCryptPasswordEncoder` bean entirely (legacy hashes still need it); do NOT change the `DaoAuthenticationProvider` wiring (it accepts the delegating encoder transparently); do NOT use `Argon2PasswordEncoder.defaultsForSpringSecurity_v5_2()` (uses weaker parameters than v5.8).
  </action>

  </verify>

  <name>Task 2: Add silent rehash-on-login in AuthService for the legacy BCrypt path</name>
