1. `HoldingRepository.findByPortfolioId` uses an explicit `@Query` (JPQL `SELECT h FROM PortfolioHolding h WHERE h.portfolioId = :portfolioId`). The new `findByPortfolioIdIn` mirrors that style with explicit JPQL `IN :portfolioIds` plus `@Param`.
2. `BillPaymentRepository` uses derived names exclusively (`findByBillIdOrderByPeriodDesc`, `findTop2ByBillIdAndStatusOrderByPeriodDesc`, `findByBillIdAndPeriod`). The two new methods follow the derived idiom: `findByBillIdInAndPeriod(Collection<UUID>, String)` and `findByBillIdInAndStatusOrderByPeriodDesc(Collection<UUID>, BillPayment.PaymentStatus)`. No `@Query`.
3. `AssetRepository extends JpaRepository<Asset, UUID>` so `findAllById(Iterable<UUID>)` is inherited. No new method on `AssetRepository`.
4. `AuditLogRepositoryDataJpaTest` lifecycle pattern (mirrored by Task 6): `@DataJpaTest` + `@EnabledIf("com.fintrack.common.AbstractDataJpaTestSupport#dockerAvailable")` + extends `AbstractDataJpaTestSupport`; `@Autowired` repositories + `EntityManager`; helper builders return entities; persists via `repo.save(...)`.
5. `entityManagerFactory.unwrap(SessionFactory.class).getStatistics()` is canonical from a `@DataJpaTest` slice. Imports: `org.hibernate.SessionFactory`, `org.hibernate.stat.Statistics`, `jakarta.persistence.EntityManagerFactory`. Hibernate `Statistics` API is on the classpath transitively via Spring Data JPA → `hibernate-core`. NO `pom.xml` change.
6. `@TestPropertySource(properties = "spring.jpa.properties.hibernate.generate_statistics=true")` is the right knob; `Statistics.setStatisticsEnabled(true)` activates the counter for the test method (the property enables collection, the API call activates it for the run). `clear()` between scenarios. `@BeforeEach` activates + clears.

Refactor adds `private final ConcurrentHashMap<UUID, PriceSnapshot> lastSnapshot = new ConcurrentHashMap<>()` and `private final AtomicBoolean firstTick = new AtomicBoolean(true)`. The `@Observed` annotation pattern follows the 26-01 / 28-* / 29-* precedent (e.g. `MonteCarloService.compute` is annotated with `@Observed(name = "analytics.monteCarlo", contextualName = "compute")`). Import: `io.micrometer.observation.annotation.Observed`.
